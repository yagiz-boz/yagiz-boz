# Yağız Boz

**Electrical & Electronics Engineering student**

I'm interested in intelligent physical systems that use sensor data to estimate what's happening and decide how to respond. I explore these ideas through battery state estimation, interactive signal-processing experiments, and an early-stage motor monitoring project.

## Engineering interests

- **Control systems** — dynamic modeling, feedback, and state estimation
- **Signal processing** — sampling, filtering, and frequency-domain analysis
- **Embedded systems and edge AI** — sensor acquisition and on-device inference for condition monitoring
- **Electrification** — battery management and electric motor systems

## Selected projects

- **[Battery SOC Estimation](https://github.com/yagiz-boz/Battery-SOC-Estimation)** — MATLAB simulation comparing coulomb counting, voltage-based estimation, and Kalman filtering under sensor noise and bias.
- **[Signal Visualizer](https://github.com/yagiz-boz/Signal-Visualizer)** — Interactive Python app for comparing time-domain waveforms and FFT spectra and exploring how windowing affects spectral leakage.
- **[Dr. Motor](https://github.com/yagiz-boz/Dr-Motor)** — Early-stage motor condition monitoring project targeting Arduino UNO Q. The current prototype validates CSV sensor records and visualizes measurements in a local dashboard.
